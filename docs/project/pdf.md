# PDF 版式和要点

本文件规定程序生成的 PDF 的版式。

- 涨跌幅对应akshare的日增长率字段。
- pdf 不落盘，用完丢弃。

## 一、页面

- 纸张：A4 竖排。
- 四边页边距：15mm。
- 不设页眉，不设页脚，不显示页码。
- 全部文字使用宋体。

## 二、顶部标题

- 全文第一页最上方，居中。
- 内容为 `Invest_Message`。
- 字号 24pt，深色。
- 顶部标题只在第一页出现，后续页面不再重复。

## 三、基金区块

每一只基金是一个区块，区块之间用一条浅灰横线分隔。

### 3.1 基金名称与代码

- 区块最上方是基金名称，左对齐，18pt 深色。
- 名称下方一行是六位基金代码，左对齐，11pt 灰色。

### 3.2 当日涨跌幅

代码下方是当日涨跌幅，按列表从上到下依次为标签、数字、日期。

- 不指定`今天`也要有当日涨跌幅数据。
- 标签：有当日数据时写「今日涨跌幅」，无当日数据时写「上一交易日涨跌幅」，13pt。
- 数字：涨跌幅百分比，带正负号、保留两位小数，34pt 加粗，左对齐。
- 颜色：上涨为红色，下跌为绿色，持平为深色。
- 日期：该涨跌幅对应的净值日期，10.5pt 灰色。
- 当日未更新时，在日期后追加「今日未更新」。

### 3.3 折线图

- 位置：当日涨跌幅之后、表格之前。
- 数量：按用户实际指定的区间词各画一张；用户查询时区间词几个就画几张。'今天'不画图和表，只写涨跌幅。
- 顺序：按区间词范围升序顺序排列。
- 图注：`近 N 天` 或 `近 N 年`，居中、加粗、13pt。
- 纵轴：相对该区间首日的累计涨跌幅，单位为百分比，保留两位小数，带正负号；左侧显示 5 个等分刻度。
- 横轴：只显示首尾两个日期。
- 坐标文字：12pt 灰色。
- 折线：深蓝色，线宽 1.2。
- 网格：横向浅灰细线。
- 宽度占满正文区，高度约 42mm。
- 折线图不跨页。

### 3.4 表格

- 位置：全部折线图之后。
- 数量：每只基金只画一张表。用户同时指定多个区间词时，只渲染覆盖范围最大的那一个。'今天'不画图和表，只写涨跌幅。
- 列：日期、单位净值、涨跌幅，共三列。
- 表头：深蓝底白字，9pt。
- 行：9pt，日期左对齐，单位净值与涨跌幅右对齐。
- 行间以浅灰细线分隔，无竖向边框。
- 排序：日期从新到旧。
- 单位净值：保留四位小数。
- 涨跌幅：保留两位小数，带正负号。
- 涨跌幅颜色：上涨红色，下跌绿色，持平深色。
- 跨页时，新页顶部重复表头。
