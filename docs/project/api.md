# 接口文档

本文件规定本程序暴露的 HTTP 接口。

程序只监听 `127.0.0.1`。

## 一、接口一览

| 方法 | 路径 |
|---|---|
| `POST` | `/help` |
| `POST` | `/query` |
| `POST` | `/watchlist` |
| `POST` | `/schedule` |

四个接口的请求体与响应格式一致。

## 二、请求体

```json
{
  "sender": "ou_55e1a0c9...",
  "args": ["今天", "7天"]
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `sender` | string | 是 | 发送者 id |
| `args` | string[] | 是 | 命令参数数组 |

## 三、响应

| 情况 | HTTP | 响应体 |
|---|---|---|
| 成功 | `200` | `{"code": 0, "message": "ok", "data": null}` |
| 失败 | `4xx/5xx` | `{"code": 0, "message": "xxx", "data": null}` |

响应立即返回，不代表业务处理已完成，业务处理与消息发送在响应之后进行。无业务码，一律返回 0。
