# 命令文档

本文件规定本程序向用户提供的全部命令、命令的写法、参数等。

## 二、命令一览

- `基金 帮助`
- `基金 查询 <区间词…>`
- `基金 查询 <代码> <区间词…>`
- `基金 自选 查询`
- `基金 自选 添加 <代码>`
- `基金 自选 删除 <代码>`
- `基金 定时 查询`
- `基金 定时 添加 <HH:MM>`
- `基金 定时 删除 <HH:MM>`

## 三、区间词

- 取值：`今天`、`7天`、`30天`、`1年`、`3年`、`5年`。

## 四、逐条说明

### 基金 帮助

- 无参数。
- 回复文字，说明全部可用命令。

### 基金 查询 <区间词…>

- 查询当前用户的全部自选基金。
- 区间词必选，可多个。
- 回复一个 PDF 文件。

### 基金 查询 <代码> <区间词…>

- 查询指定的单只基金。
- 第一个参数必须是六位数字代码，其后的词全部是区间词。
- 区间词必选，可多个。
- 回复一个 PDF 文件。

### 基金 自选 查询

- 无参数。
- 回复文字，逐行列出该用户的自选，每行包含代码与名称。

### 基金 自选 添加 <代码>

- 参数必须为六位数字。
- 一次只添加一只。

### 基金 自选 删除 <代码>

- 参数必须一个六位数字。

### 基金 定时 查询

- 逐行列出该用户设置的全部时间点，升序排列。

### 基金 定时 添加 <HH:MM>

- 参数必须一个格式为 24 小时制的 `HH:MM`。

### 基金 定时 删除 <HH:MM>

- 参数必须一个格式为 24 小时制。
